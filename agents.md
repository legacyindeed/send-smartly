# Skill: frontend-ui-polish

## Purpose
Upgrade an existing webpage from rough/basic to polished, modern, and visually coherent without changing the product’s core functionality.

## When to use
Use this skill whenever the UI looks messy, outdated, inconsistent, cramped, or unprofessional.

## Goals
- Make the interface look clean, modern, and product-quality
- Improve spacing, typography, hierarchy, and alignment
- Create stronger visual consistency across sections
- Improve responsiveness on desktop and mobile
- Preserve existing functionality unless a UI change clearly improves usability

## Design principles
- Prioritize clarity over decoration
- Use strong spacing and visual hierarchy
- Reduce clutter and unnecessary borders
- Make one primary action obvious on each screen
- Keep layouts balanced and breathable
- Use consistent radius, shadows, and padding
- Prefer simple premium styling over flashy styling
- Make the page feel like a modern SaaS product

## Visual standards
- Use a clean layout grid
- Increase whitespace between sections
- Use larger headings with clearer section hierarchy
- Standardize button styles, input styles, and card styles
- Use one accent color consistently
- Improve contrast and readability
- Use subtle shadows and soft borders
- Avoid tiny text and cramped components
- Make cards and containers look intentional, not randomly boxed

## UX improvements
- Improve scanability
- Group related information clearly
- Reduce cognitive overload
- Make important information visible first
- Ensure forms are easy to understand and complete
- Improve empty states and loading states if needed
- Improve hover, focus, and active states

## Responsive behavior
- Ensure layout works well on mobile, tablet, and desktop
- Prevent overflowing text or broken sections
- Stack sections intelligently on smaller screens
- Keep tap targets comfortable on mobile

## Implementation workflow
1. Audit the current page and identify the top UI issues
2. Improve layout structure first
3. Improve typography and spacing second
4. Standardize reusable UI patterns
5. Polish colors, shadows, borders, and states
6. Improve responsiveness
7. Do a final pass for visual consistency

## Output expectations
When applying this skill:
- first explain the major UI problems found
- then implement improvements directly in code
- keep changes practical and shippable
- avoid unnecessary libraries unless clearly beneficial
- prefer maintainable CSS/components over hacks

## Style reference
Aim for a feel somewhere between:
- Linear
- Stripe
- Vercel
- modern fintech/product dashboards

## Hard constraints
- Do not break existing logic
- Do not remove important content
- Do not overdesign
- Do not introduce random colors or inconsistent spacing
- Do not add animations unless they clearly improve the experience
